ShubhTechIN favicon and social-preview assets

1. Extract the ZIP.
2. Copy every image file inside the included `public` folder into your project's `public` folder.
   Do not delete your existing resume PDF or other public files.
3. Replace `app/layout.tsx` with the included `layout.tsx`.
4. Run `npm run build` to check for errors.
5. Commit and push:
   git add public app/layout.tsx
   git commit -m "Add favicon and social preview image"
   git push

The metadata points to https://shubham-portfolio-mu-puce.vercel.app.
Social preview caches can take time to refresh after deployment.
